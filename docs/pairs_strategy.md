# 配对交易契约 v1

## 目的

把"两个价格看起来相关"变成一次可审计的双边回测。这个契约回答三件事：

1. 这两个标的到底有没有稳定的长期关系（协整检验）；
2. 如果有，价差被拉离均值之后会不会回来（半衰期、分桶前向行为）；
3. 回来的时候，扣掉两条腿的手续费、滑点和借券费之后还剩多少。

第 1 步不通过时，第 3 步的结果没有意义——那不是策略，是巧合。

## 输入

| 输入 | 来源 | 必要性 |
|---|---|---|
| 两条腿的日频复权收盘价 | `data/raw/market/<SYM>.csv` 快照，或 `config/data_catalog.yaml` 里的 yahoo 条目 | 必须 |
| 交易日历 | 两条腿共同的报价日（缺失日剔除，不前向填充） | 必须 |
| 回看窗口 | `--lookback`，默认 60 个交易日 | 必须 |
| 对冲比率 β | 滚动 OLS，见下 | 必须 |
| 进出场阈值 | `--entry-z` / `--exit-z`，默认 ±2 / ±0.5 | 必须 |
| 手续费、滑点 | `--fee-bps`（默认 5）、`--slippage-bps`（默认 2） | 必须 |
| 借券费 | `--borrow-bps`（默认 50，按年） | 严谨回测必须 |
| 无风险利率 | `--risk-free-rate`，默认 0 | 进阶 |

价格用 Yahoo `auto_adjust=True` 的后向复权价，已包含拆股与分红的影响，但**没有 point-in-time 版本**：今天的公司行为会回溯改写整段历史。复权价适合价格收益型配对，不适合声称"当时可见"的结论。

## 统计口径

- **价差**：`log(P_a) − β·log(P_b) − α`（`--price-kind level` 用原始价差）。
- **对冲比率**：滚动 OLS，窗口为 `[t−L, t−1]`，即 `t` 日的 β 只用 `t` 日之前的数据估计。这一条是整个模块最关键的防前视约束：β 是建价差的输入，不能用它自己未来的信息。
- **α**：同一滚动窗口的均值，同样滞后一期。
- **Z 值**：`spread` 的滚动均值/标准差，窗口同样取 `[t−L+1, t]`。
- **协整检验**：Engle-Granger——`log(P_a)` 对 `log(P_b)` 回归取残差，对残差做 ADF（无常数项），统计量与 MacKinnon 大样本临界值比较（5% 为 −3.03）。
- **半衰期**：`ΔS_t = a + b·S_{t−1}` 回归，`b < 0` 时半衰期为 `−ln(2)/b`。`b ≥ 0` 说明价差在漂移而不是回归，此时 Z 值不代表任何均值回复。

## 交易规则

- Z ≥ entry_z：做空价差（空 A、多 B）；Z ≤ −entry_z：做多价差。
- 持有中 |Z| ≤ exit_z：两腿同时平掉。
- 可选止损（`--stop-z`）与最长持有（`--max-holding-days`）。**止损或超时之后不再立即重开**，直到价差回到 exit 区间为止，否则会在同一个极值上反复止损。
- 只有开仓和平仓日才下达目标权重指令；两个持有日之间权重随价格漂移（不每日再平衡对冲比率）。

## 权重口径

| 模式 | 权重 | 含义 |
|---|---|---|
| `beta_neutral`（默认） | `w_a = p/(1+β)`，`w_b = −p·β/(1+β)` | 一单位价差敞口，总敞口 = 1 |
| `dollar_neutral` | `w_a = p/2`，`w_b = −p/2` | 美元中性，敞口为价格比而非 β 调整后的价差 |

`p` 为 +1（做多价差）或 −1（做空价差）。默认的 `beta_neutral` 使组合收益等于 `p·(r_a − β·r_b)/(1+β)`，与所交易的价差口径一致；美元中性会交易一个不同的敞口。

## 记账契约

与 `docs/backtest_contract.md` 一致：

- 第 `t` 行收益是 close(t−1) 到 close(t) 的区间；
- `t` 日的信号在 close(t+lag) 成交，默认 lag = 1，不允许同收盘价成交；
- 成交当日的收益仍归成交前的持仓；
- 空头所得作为零息现金留存，因此总敞口 = `Σ|w|`、净敞口 = `Σw`；
- 借券费按持有空头腿的区间逐日计提，先于手续费扣除；
- 手续费与滑点按成交名义额计提；
- 持仓在两次指令之间随价格漂移。

## 反泄漏规则

1. 对冲比率与截距只用 `t` 之前的数据；
2. Z 值只用 `t` 及之前的数据；
3. 不做全样本标准化后再回测；
4. 不填充缺失价格，只剔除共同报价日；
5. 参数不能用同一段数据选完再汇报——先定参数，再看样本外。

## 实际结果（2026-10-26，26 对同行业美股）

`config/pairs.yaml` 里 26 对同行业标的（软饮料、必需消费、银行、能源、医药、半导体、电信、航空、汽车、化工、机械），Yahoo 后向复权价，2005–2026。

**全样本筛选**：26 对里 5 对通过协整与半衰期门槛（T/VZ、GS/MS、HSY/MDLZ、HRL/CAG、MCD/YUM）。KO/PEP 不通过：其价格比 2010 年 0.50 → 2023 年 0.35 → 2026 年 0.68，对数价格的 ADF 不拒绝单位根。

**全样本回测**（用同一段数据选出的 5 对）：等权组合 CAGR +0.02%、Sharpe 0.02、最大回撤 −10.8%，交易成本 8.5–9.6%。**这个数字没有意义**，因为筛选和回测用的是同一段数据。

**滚动 walk-forward**（每折只用样本内筛选，样本外交易）：

| 样本内 | 样本外 | 入选对数 | 组合 CAGR | 组合 Sharpe | 最大回撤 |
|---|---|---|---|---|---|
| 2005–2009 | 2010–2014 | 3 | −0.78% | −0.26 | −6.1% |
| 2010–2014 | 2015–2019 | 5 | −1.46% | −0.52 | −9.6% |
| 2015–2019 | 2020–2026 | 4 | −1.78% | −0.54 | −15.7% |

三折全负。单切分（2005–2014 选、2015–2026 交易）曾给出 +2.21%、Sharpe 0.50 —— 那是切分运气，不是边际。

**零成本对照**（2015–2019 那一折，手续费/滑点/借券费全设为 0）：组合 CAGR −1.09%、Sharpe −0.38。成本只解释约 0.4 个百分点，**亏损主要在信号本身**，不是被费用吃掉的薄边际。

结论：这套机制（点时约束、协整检验、双边记账、成本与借券费、样本外流程）是对的，但在这 26 对、这组参数上，Z 值策略没有可交易的样本外边际。要继续做，方向是换信号（用半衰期匹配的持有期、降低换手、去掉滚动 β 的自指），而不是调阈值把曲线调好看。

## 局限

- 单对标的、单参数，没有跨标的稳健性检验；
- 借券费率是假设值，真实费率随标的与时间变化，且可能根本借不到券；
- 没有成交量约束：当前价格源只取收盘价，不含成交量，无法检查冲击成本与容量；
- 没有税费、没有现金利息（现金按 0 收益处理，偏保守）。

## 校验阶梯

1. 合成数据测试：记账、漂移、借券费、止损后不重开；
2. 单变量检查：把价差做成纯随机游走，确认协整检验不通过、Z 值策略不产生"稳定盈利"的假象；
3. 已知的协整合成对：确认检验通过、方向正确；
4. 真实标的：先看年末价格比是否在走趋势——**价格比持续单向移动时，这不是一个价差，而是一个趋势**；
5. 最后才是样本外与参数稳健性。
